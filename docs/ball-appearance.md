# 悬浮球外观（0.6.0-dev）

日期：2026-11-14。用户确认透明度 20%–100%、默认 100%、即时预览并记住，同时增加多款悬浮球供选择。

## 使用

面板左下角设置图标进入设置页，在既有使用记录和悬浮球开关之后显示「悬浮球外观」。点选样式，拖动透明度滑块即可生效，不需要额外保存按钮。没有开启悬浮球时也能设置外观，不会因此启动服务或申请通知权限。

预览默认为 48dp 实物大小（2026-11-17 起可在后面的「布局与大小」调为 32–80dp），棋盘底用于判断透明程度；样式选项维持不透明，以便对照图形，当前预览按滑块值显示。球在设置面板打开时仍隐藏，收起面板后显示最新外观。最低值保留 20%，避免完全透明后找不到入口；触摸区域至少为 48dp，大于 48dp 时随图形增大。

## 五款设计

沿用司南的方向/罗盘意象，不只更换底色：

| 样式 | 图形和配色 |
| --- | --- |
| 经典 | 保留司南原标识，品牌蓝圆底 |
| 游标 | 浅底蓝色细环与方向箭头，轮廓轻量 |
| 北辰 | 深蓝底四芒星与一颗金色定位点 |
| 墨玉 | 墨绿底、金色刻度环与双色磁针 |
| 朱砂 | 朱红圆角印章、浅色边框与「南」字 |

色板：品牌蓝 `#2954CE`、浅色 `#EFF4FC`、深蓝 `#18243C`、墨绿 `#143E38`、金色 `#D7B77B`、朱红 `#B44432`。字体沿用原生 sans，设置标题与百分比有明确层级。没有装饰性渐变或自动动画；选中边框表示当前样式，单选控件保留无障碍选中状态。

图形使用原生 Drawable/Canvas 绘制，经典款复用已有品牌矢量；设置预览与真实球使用同一绘制类。五款内置样式均为应用内图形。

## 配置与更新

`BallAppearanceStore` 由 Application 持有，当前配置为样式 ID、整数透明度与大小 dp。配置读写在单独后台线程串行进行；主线程只更新内存与发布观察回调。滑动连续变化合并为 200ms 写入，松手/离开设置页时提交待保存值；辅助功能调整没有松手事件时也会在延迟后保存。

配置文件为应用私有 `shared_prefs/floating-ball-appearance.xml`，不保存服务启用状态、操作次数或逐次日志；自动备份仍关闭。未知样式回退经典，透明度约束到 20–100，读取失败回退默认值。下次进程加载完成后再显示真实球，避免先闪出默认皮肤。

服务订阅外观变化，样式更新图形，透明度设置到整个球窗口的 alpha，不重启服务；大小变化按原贴边方向和垂直比例重新定位。关闭球仍保留外观；进程/设备结束后依旧需要手动开启球。使用记录清空不影响外观或贴边位置。

## 自定义图片（2026-11-18）

「悬浮球外观」的内置样式下方提供「选择悬浮球图片」。导入后显示在实物预览和实际悬浮球中，图片居中填充并裁成圆形，保留图片透明区域。悬浮球原有大小与透明度继续生效。点击「恢复内置样式」会使用上次所选的内置样式，也可直接选择任一内置样式。

设置页末尾的「面板背景图」支持选择、更换及恢复默认。图片居中填充面板，保留顶部圆角，并叠加随系统深浅色变化的遮罩。布局设置中的面板背景不透明度作用于合成后的整个背景。没有悬浮权限时，可通过普通页面的「设置 → 自定义外观」提前设置两处图片。

系统文件选择器仅授权读取所选图片。应用在后台将面板图片长边限制到 2048 像素、球图片长边限制到 512 像素，重新编码为 PNG，通过 AtomicFile 写入应用私有不备份目录。处理图片时保留拍摄方向和像素透明度，更换时覆盖对应的旧副本，恢复时删除对应副本。取消或导入失败保留当前外观。修改图片不会开启悬浮球或新增权限请求。

### 图片场景验证

- Android 15（API 35）模拟器通过系统选择器实测两处导入、面板换图、恢复默认背景及恢复内置球样式。普通降级页也可导入并恢复两处图片。
- 使用合成测试图片验证长边限制。取消选择和导入损坏图片后，已保存的面板图片保持原样；关闭设置仍保留此前输入的搜索数字，重启应用后背景图继续显示。
- 检查了面板顶部圆角及图片显示，确认真实圆形悬浮球显示自定义图案并可点击打开面板。
- Debug 构建、Lint 和搜索模块构建通过。API 35 原有 T9 与系统入口回归、悬浮球外观及生命周期专项回归均通过。
- API 26–27 的兼容解码分支、API 36、厂商真机和完整 TalkBack 未实测。
