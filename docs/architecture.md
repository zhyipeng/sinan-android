# 技术架构

## 技术基线与当前实现

Kotlin + Android 原生 View，最低 API 26，编译与目标 API 36。当前工程实际只有 `app` 与 `core/search` 两个模块，不提前拆分大量 Gradle 模块。

`app` 包含一个使用系统栏 Insets 的说明页；`core/search` 包含应用 ID、索引条目和搜索结果模型。下列组件均为后续设计，尚未实现。

| 组件 | 职责与依赖边界 |
| --- | --- |
| AppRepository | 获取可启动入口、用户配置文件标识及应用变化；输出平台无关条目 |
| PinyinProvider / IndexBuilder | 离线词组拼音、变体、别名与 T9 编码；后台构建快照 |
| SearchEngine / UsageRanker | 纯 Kotlin 匹配与确定性排序；接收索引、时钟、统计快照 |
| UsageRepository | 工具内事件、可选系统事件、聚合与清除 |
| SearchController | 管理查询、面板会话及过期搜索任务取消 |
| FloatingPanelManager | WindowManager、焦点、触摸边界、显示/隐藏及资源释放 |
| AppLauncher | 根据 profile + component 启动，处理失效入口与受限资料 |
| EntryPoints | Activity、快捷方式、磁贴及可选悬浮球，共用唤出流程 |

设置拟采用 DataStore；事件与聚合拟采用 Room。只有对应功能开始实现时才添加依赖。拼音库通过适配接口隔离，候选 TinyPinyin 需先验证词组、多音字、维护状态与许可证；不视为已采用。

## 数据流

```text
应用扫描/变更 → 词组拼音与数字编码 → 不可变索引快照
系统可选事件 + 工具内启动 → 去重与聚合 → 使用特征快照

用户主动唤出 → 固定索引/使用快照 → 默认推荐
T9 输入 → 匹配候选 → 等级排序 → 按 AppId 去重 → 网格
点击 AppId → 系统启动请求 → 记录提交结果 → 收起面板
```

应用启动请求被系统接受不等于目标已展示在前台。无可靠确认时，事件应标为工具内“启动请求”，不可宣称为实际系统使用事件。

## 窗口与生命周期

面板状态建议为 `Hidden → Opening → Visible → Launching/Closing → Hidden`。同一时刻只允许一个面板实例；重复唤出按状态合并，所有 WindowManager 变更在主线程串行执行。

- 打开时检查权限与宿主状态；无悬浮权限进入 Activity 降级视图。
- 跨应用窗口拟使用 `TYPE_APPLICATION_OVERLAY`；键盘由应用自身绘制，焦点、返回键、触摸穿透与外部点击需专门验证。
- 普通面板按需创建，关闭后移除窗口、解除监听和释放宿主；不默认依赖永久常驻服务。
- 可选悬浮球需要单独验证合法的服务生命周期、通知、进程终止恢复与用户关闭路径。
- 后台刷新只供下次面板使用；应用卸载等失效可令当前格子失效，不在手指按下时重新排位。
- 搜索任务具有递增查询版本号，只发布当前查询与索引版本对应的结果。

## 标识、索引与数据

应用 ID = 用户资料序列号 + 包名 + 完整 Activity 名。序列号由 Android 适配层取得；不使用对象哈希，也不假设包名能唯一表示启动入口。

普通应用能看到的应用和资料范围受平台约束；工作资料支持属于兼容性验证项，不承诺跨全部资料访问。系统使用事件常只有包或 Activity 线索，无法可靠定位到入口时按资料/包级保存统计并明确共享，不能伪造入口级精度。

索引仅保存文本与匹配元数据，不包含图标 Bitmap。图标单独按密度与资料身份缓存，采用有界内存缓存。扫描与索引在后台完成，通过原子替换快照发布；增删包、语言变化、名称变化后更新。进程冷启动没有缓存时显示加载状态，不在主线程同步全量扫描。

## 需要设备验证的系统边界

原会话提及的 Android API 行为只作为待验证线索。实现时应查阅对应目标版本的最新官方文档，完成下列验证后才能确认入口方案。

| 验证项 | 通过标准 |
| --- | --- |
| Activity / 磁贴主动唤出 | 锁屏与解锁状态行为清晰，允许路径稳定可用 |
| 后台 Activity 与服务启动限制 | 不依赖隐藏悬浮窗权限绕过限制；合法路径实机可重复 |
| 悬浮球服务 | 验证服务类型、后台启动条件、通知和关闭清理 |
| 悬浮窗与底层触摸 | 不吞掉面板外交互，不制造误触或卡住返回键 |
| 应用可见性 | 最小声明能列出预期启动入口；工作资料不可见时降级 |
| UsageStats 事件 | 授权撤销、有限事件窗口、重复事件、时钟改变有处理 |
| 屏幕适配 | 全面屏手势、导航栏、横屏、折叠屏、字体缩放可操作 |

建议覆盖最低支持版本、API 35/36 和至少两类常见厂商真机。仅有编译和 Lint 通过不能关闭这些任务。
