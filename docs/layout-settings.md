# 布局与大小设置

2026-11-17：用户确认面板宽高独立调节、仅背景透明、球与图标大小独立调节，以及自动或 2–6 列网格。

## 入口与范围

面板内设置页，在既有「悬浮球外观」之后追加「布局与大小」。普通 Activity 降级页的设置菜单也提供该入口，没有悬浮权限时仍可调整图标与列数、预先配置面板和球。

| 设置 | 范围 | 默认 | 生效规则 |
| --- | --- | --- | --- |
| 面板宽度 | 70%–120% | 100% | 相对既有宽度（显示宽度与 560dp 的较小值）；最低 320dp，不超过屏幕 |
| 面板高度 | 75%–120% | 100% | 相对既有竖屏 79% / 横屏 90% 的显示高度；最高屏幕 95%，最低竖屏 520dp / 横屏 320dp，屏幕不足时以实际高度上限为准 |
| 面板背景不透明度 | 20%–100% | 100% | 只改变圆角窗口背景，不改变图标、文字、键盘和设置卡片的透明度 |
| 悬浮球大小 | 32–80dp | 48dp | 实际图形和设置预览同步；触摸窗口至少 48dp，小球居中显示 |
| 应用图标大小 | 32–72dp | 48dp | 网格单元空间不足时缩小图标，不跨越相邻单元 |
| 网格列数 | 自动、2–6 列 | 自动 | 自动按可用宽度与图标大小适配；手动列数也受最小 56dp 单元宽度限制 |
| 键盘大小 | 80%–130% | 100% | 竖屏调节按键高度，横屏同时调节键盘列宽；文字和功能图标同步缩放，受可用空间限制 |

百分比指相对默认面板尺寸，滑块值是期望值，实际尺寸受屏幕约束。默认值保留既有常规尺寸；极矮屏幕可能触发最低可操作尺寸限制。网格保持可滚动。改变设置不会开启悬浮球、申请权限或记录搜索词。

## 实现

`LayoutPreferencesStore` 保存宽度比例、高度比例、背景不透明度、图标 dp、列数与键盘比例；0 列表示自动。Application 持有内存快照，后台单线程加载与写入 `shared_prefs/layout-preferences.xml`，不增加依赖。球大小追加到原有 `BallAppearanceStore`，旧配置缺少该字段时使用 48dp。

首次后台加载完成前禁用滑块，避免覆盖已保存配置。滑动即时发布内存更新，200ms 合并写入，松手或离开页面提交待保存值；无障碍调整也可延迟保存。读取失败回退默认值，数值读入与更新均限制范围。设置不进入备份；与使用统计独立。

`PanelActivity` 订阅配置并更新背景与窗口边界，显示变化时重新计算。`AppGridView` 保留查询与使用快照，仅更新列数和图标绑定，不重新执行搜索或重新排序。悬浮球大小变化时按原贴边方向与垂直比例重新定位，取消旧触摸，防止窗口变动误触。

## 键盘与按钮补充（2026-11-17）

用户确认采用单个键盘比例滑块，追加在列数设置后面，默认 100%。旧配置没有 `keyboard-size` 字段时保留默认大小；与其他布局设置相同，后台合并保存，即时生效。调整不会清空查询或重建搜索快照。

键盘缩小时保留至少 48dp 按键高度；横屏键盘列最小 160dp，保留结果区。为满足小面板下的触摸尺寸，横屏面板最低高度由 270dp 提高至 320dp，仍受屏幕高度 95% 的上限限制。极小窗口无法容纳最小触摸区时按实际可用空间布局，避免越界。数字和字母在矮屏自动并排，并按可用宽高限制文字大小。

「悬浮球后台运行设置」按钮复用 `styleActionButton`：语义色、圆角、细边框、原生字体及按压缩放/触感反馈，与现有按钮一致；后台设置操作保持原实现。

普通降级页横屏时将品牌、使用记录与权限入口合并到同一行，收起较长的权限说明，为键盘保留高度；竖屏保持原布局。
