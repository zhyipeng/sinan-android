# 布局与大小设置

2026-11-17：用户确认面板宽高独立调节、仅背景透明、球与图标大小独立调节，以及自动或 2–6 列网格。

## 入口与范围

面板内设置页，在既有「悬浮球外观」之后追加「布局与大小」。普通 Activity 降级页的设置菜单也提供该入口，没有悬浮权限时仍可调整图标与列数、预先配置面板和球。

| 设置 | 范围 | 默认 | 生效规则 |
| --- | --- | --- | --- |
| 面板宽度 | 70%–120% | 100% | 相对既有宽度（显示宽度与 560dp 的较小值）；最低 320dp，不超过屏幕 |
| 面板高度 | 75%–120% | 100% | 相对既有竖屏 79% / 横屏 90% 的显示高度；最高屏幕 95%，最低竖屏 520dp / 横屏 270dp，屏幕不足时以实际高度上限为准 |
| 面板背景不透明度 | 20%–100% | 100% | 只改变圆角窗口背景，不改变图标、文字、键盘和设置卡片的透明度 |
| 悬浮球大小 | 32–80dp | 48dp | 实际图形和设置预览同步；触摸窗口至少 48dp，小球居中显示 |
| 应用图标大小 | 32–72dp | 48dp | 网格单元空间不足时缩小图标，不跨越相邻单元 |
| 网格列数 | 自动、2–6 列 | 自动 | 自动按可用宽度与图标大小适配；手动列数也受最小 56dp 单元宽度限制 |

百分比指相对默认面板尺寸，滑块值是期望值，实际尺寸受屏幕约束。默认值保留既有常规尺寸；极矮屏幕可能触发最低可操作尺寸限制。网格保持可滚动。改变设置不会开启悬浮球、申请权限或记录搜索词。

## 实现

`LayoutPreferencesStore` 保存宽度比例、高度比例、背景不透明度、图标 dp 与列数；0 表示自动。Application 持有内存快照，后台单线程加载与写入 `shared_prefs/layout-preferences.xml`，不增加依赖。球大小追加到原有 `BallAppearanceStore`，旧配置缺少该字段时使用 48dp。

首次后台加载完成前禁用滑块，避免覆盖已保存配置。滑动即时发布内存更新，200ms 合并写入，松手或离开页面提交待保存值；无障碍调整也可延迟保存。读取失败回退默认值，数值读入与更新均限制范围。设置不进入备份；与使用统计独立。

`PanelActivity` 订阅配置并更新背景与窗口边界，显示变化时重新计算。`AppGridView` 保留查询与使用快照，仅更新列数和图标绑定，不重新执行搜索或重新排序。悬浮球大小变化时按原贴边方向与垂直比例重新定位，取消旧触摸，防止窗口变动误触。

## 验证

```bash
./gradlew :app:assembleDebug :app:lintDebug :core:search:build --offline --console=plain
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
python3 tools/smoke_layout_android.py --serial emulator-5554
python3 tools/smoke_android.py --serial emulator-5554
python3 tools/smoke_ball_android.py --appearance --serial emulator-5554
```

布局专项脚本仅操作模拟器；备份并恢复布局、球外观、位置及其 `.bak` 文件，恢复悬浮/通知权限、字体、旋转及固定旋转策略，结束时球关闭；不读取使用统计。异常后如果遗留备份目录会拒绝覆盖，需先检查恢复。

### 本次实测（API 35 模拟器）

- Debug 构建、Lint、搜索模块构建通过；Lint 无问题，搜索模块现有 24 项测试无失败（本轮未修改匹配/排序）。
- 通过设置滑块验证面板宽高缩小、背景 20% 不透明度、72dp 图标和期望六列的空间适配；配置跨进程保存。
- 真实球窗口 80dp；运行中缩为 32dp 后不重启进程，触摸窗口仍为 48dp，并能点击打开面板。
- 实际横屏窗口宽大于高的断言通过；150% 字号下可操作布局滑块、返回搜索，并使用自动列数与 32dp 图标。
- 撤销悬浮权限后通过普通页面设置菜单修改为 72dp 图标与两列，未创建悬浮窗口。
- 原有系统入口/T9 完整回归通过，包括权限降级、使用汇总恢复、面板关闭、磁贴及返回保留查询。悬浮球完整外观回归通过，包括通知拒绝/允许、拖动贴边、跨进程位置、锁屏恢复、通知关闭及悬浮权限撤销清理；结束时原配置已恢复，球关闭。
- 最低版本、API 29/36、厂商真机及完整 TalkBack 调节尚未实测；本轮不沿用旧版本记录宣称这些环境已通过新增布局设置。
