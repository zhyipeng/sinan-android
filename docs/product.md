# 司南产品方案

日期：2026-11-12。状态：立项基线，尚未完成 MVP。

## 需求来源与定位

来源：[设计安卓效率工具](chatgpt-conversation://6af58939-b008-83e8-a513-9f40fc13c38b)。原会话共三轮：初始构想、网格与按需唤出确认、T9 与排序设计讨论。

用户明确提出：快速搜索并启动 App；默认悬浮面板；内置以九宫格为主的键盘；拼音 T9 搜索；可选悬浮球；结果以 App 网格呈现；无输入时按近期使用频率智能排序；面板按需唤出。本次确认产品名为「司南」，并要求建立可编译工程骨架。

定位：在当前应用之上按需打开的效率入口。以应用搜索和启动为核心，不扩展为完整桌面替代品。

## MVP 功能

| 功能 | 范围与优先级 |
| --- | --- |
| 按需唤出与收起 | P0；默认不显示面板；启动成功后收起 |
| 应用网格 | P0；原生图标与名称；可滚动；布局不挤压键盘 |
| 内置 T9 | P0；2–9 字母映射，退格、清空；不打开系统输入法 |
| 搜索 | P0；首字母、全拼、混合拼音、英文名称；离线运行 |
| 应用发现与启动 | P0；只索引可见、可启动入口；变更后刷新 |
| 默认排序 | P0；近期与频率综合；权限不足时使用工具内记录 |
| 基础设置与权限引导 | P0；明确权限用途和拒绝后的可用功能 |
| 快捷入口 | P0 验证桌面入口，优先评估快捷设置磁贴 |
| 悬浮球 | P1；可选开关、拖动、贴边；不作为唯一唤出方式 |
| 置顶和自定义别名 | P1；引擎预留，完整编辑 UI 后续添加 |
| 查询偏好学习 | P1；同匹配等级内生效，有时间衰减，可清除 |

联系人、系统设置搜索、付款扫码深链、插件、手势服务、数字编辑距离容错及云同步均不在 MVP 范围。

四列网格、底部面板、默认 Top 24 候选、退格长按清空为原会话建议，作为原型默认值验证；Top 24 指返回候选上限，不代表首屏必须展示 24 个图标。列数和高度随屏幕、字号及方向适配。

## 关键交互

1. 从用户主动触发的入口唤出面板。
2. 无输入时展示智能排序网格；首次使用没有数据时按规范化名称及稳定 ID 排序。
3. 输入数字后实时过滤；支持首字母与全拼混输，不显示拼音选字候选。
4. 点击结果后请求启动。成功提交系统启动请求后收起；失败则反馈原因并保留重试入口。
5. 点击面板外区域或返回键收起；重新唤出默认清空查询并获取新排序快照。
6. 面板无顶部标题、设置/关闭按钮、输入提示或数量栏；数字显示在键盘上方。键盘底行为设置图标 / 0 / 退格图标，退格短按删除、长按清空。

无结果显示清空或退格提示，不自动回落到无关推荐。应用卸载、禁用或工作资料锁定时，启动失败应移除失效候选或提示刷新。面板按下图标到启动请求处理结束期间固定目标 ID，不因刷新改变点击对象。

## 权限与隐私

| 能力 | 授权与降级方案 |
| --- | --- |
| 跨应用悬浮面板 | 按需引导悬浮窗特殊授权；拒绝时提供 Activity 内搜索面板 |
| 全局使用习惯 | 使用情况访问权限可选；拒绝或撤销后仅使用工具内启动统计 |
| 悬浮球后台生命周期 | 用户启用时评估服务和通知需求；关闭后释放相关资源 |
| 应用发现 | 最小化可见性声明；不默认申请全量包查询能力 |

所有使用信息默认留在本地。设置中应支持清空历史和查询偏好，明确置顶/别名是否一并清除。不开启云端上传或第三方埋点。

2026-11-13 用户已确认：仅保存工具内启动请求的小时汇总及最近一次时间，保留 30 天，不保存逐次日志或搜索词；使用时清理，支持清空。查询偏好未实现，后续采集范围须重新确认。备份暂关闭，避免使用习惯被自动迁移。

## MVP 验收

- 断网可完成应用扫描、搜索与启动；没有使用情况权限仍可用。
- 微信 `99`、支付宝 `932`、抖音 `39`、淘宝 `82` 等固定样例命中；多音字和混合匹配详见引擎文档。
- 网格可滚动、键盘位置稳定；不弹系统输入法；无结果不隐藏键盘。
- 从默认隐藏状态可靠唤出；悬浮球关闭不影响其他入口。
- 用户按下图标时不会因后台统计刷新启动另一个应用。
- 拒绝/撤销权限、应用变更、快速重复唤出、旋转和进程重建均有明确处理。
- 性能目标通过指定测试设备验证，不能以桌面 JVM 结果代替 Android 端数据。
